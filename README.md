## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites

To open this project locally, you will need to install the following first:
- [Unity Hub](https://docs.unity.com/en-us/hub)
- [VRChat Creator Companion](https://vcc.docs.vrchat.com/) or [ALCOM](https://vrc-get.anatawa12.com/en/alcom/)
- [GIT-LFS](https://git-lfs.com/)

Additionally, you will need to add the following repositories to VCC/ALCOM:
- [VRCFury](https://vrcfury.com/)
- [Poiyomi Toon Shader](https://www.poiyomi.com/)
- [Gesture Manager](https://github.com/BlackStartx/VRC-Gesture-Manager) (optional)


### Installation

1. Clone the repo
```sh
git clone https://github.com/The-Best-Boi-Project/model-hd.git
```
3. Open VCC/ALCOM and add the cloned repo as an existing project
4. Click on "manage"
5. Add the required packages listed above
